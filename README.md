# PumpfunCP - Token Creation Platform

A modern web application built with Next.js that enables users to create and deploy tokens with ease. This platform provides a user-friendly interface for token creation and IPFS integration.

## Features

- 🔐 Wallet Connection Integration
- 🪙 Token Creation Interface
- 📁 IPFS File Upload Support
- ⚡ Real-time Token Creation Status
- 🎨 Modern UI with Tailwind CSS

## Tech Stack

- Next.js 13+ (App Router)
- TypeScript
- Tailwind CSS
- Web3 Integration
- IPFS Integration

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Belacosaur/PumpfunCP.git
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `/app` - Next.js application routes and components
- `/app/components` - Reusable React components
- `/app/api` - API routes for token creation and IPFS
- `/app/lib` - Utility functions and configurations
